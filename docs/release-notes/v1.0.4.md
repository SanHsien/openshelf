## OpenShelf v1.0.4

歷史重建後的首個 Release。`v1.0.3` 與目前 `main` 沒有共同祖先，GitHub 無法產生
`v1.0.3...v1.0.4` 的可信差異，因此本版改用人工整理的 release notes（見
`REPO_REVIEW.md` P1「Release tag 與目前 `main` 沒有共同祖先」）。已公開的 `v1.0.3`
保留不動，之後所有 tag 都會從 `main` 的後代建立，恢復連續歷史。

### 修正

- **介面語言偵測**：改用 `QLocale.system().name()` 判斷系統語系，標準庫僅作後援。
  原本依賴的 `locale.getdefaultlocale()` 已棄用（Python 3.15 將移除），且在 Windows
  可能回傳 `Chinese (Traditional)_Taiwan` 這種格式而誤判為英文介面。
- **狀態列標示**：逾時的 `.acsm` 由 `ACSM` 改為 `ACSM 逾時` / `stale ACSM`，
  不再與一般 ACSM 計數混淆。
- **登入確認對話框**：改走 i18n，英文介面不再出現中文字串。

### 依賴

最低版本更新為 `playwright>=1.62.0` 與 `packaging>=26.3`；其餘直接依賴已是最新。
兩者皆為 minor／patch，`requires_python` 涵蓋本專案的 `>=3.11`。

### 維護

- 每週 Dependabot 與每月依賴新鮮度檢查上線，只有 allowlist 內的 low-risk 更新可
  guarded auto-merge，其餘人工審查。
- 新增 i18n 與依賴自動化的單元測試。

### 已知限制

- macOS / Linux 產物僅由 CI 建置，尚未在對應系統實機測試。
- 本版未重跑真實 Google 登入流程驗證；`openshelf/browser.py` 只使用 Playwright
  的穩定 API（`sync_playwright()`、`chromium.launch_persistent_context()`）。
- Release 尚未使用 constraints／lock，建置時安裝當下最新依賴（`REPO_REVIEW.md` P2）。

### 資產

Windows 精簡版 zip、可攜版 zip（含 Chromium）、`setup.exe` 安裝程式；
macOS `OpenShelf.app` zip；Linux 執行檔 zip。皆附 `.sha256` 校驗檔。
